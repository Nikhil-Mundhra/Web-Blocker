Rule Syntax Reference Guide

Configure precise rules to block or allow domains, subdomains, paths, query parameters, or tab titles:

Pattern Meaning Example
example.com Block entire domain and subpages reddit.com
!rule Allow / Exclude from blocking (Whitelist) !sub.example.com
* Wildcard: matches 0 or more characters *.example.com/*, *shorts*
? Single character match example.com/???/
\? Literal question mark (for query strings) youtube.com/watch\?v=*
/regex/ Regular expression matching /.{3,}\.example\.com/
title:*word* Match against tab / page title title:*Shorts*
Note: In Approved Sites Only mode, all web browsing is blocked except for rules prefixed with !.
