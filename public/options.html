Syntax Reference Guide

You can configure rules to block or allow domains, subdomains, specific paths, query parameters, or page titles.

Pattern Meaning Example
example.com Block domain and any subpages reddit.com
!rule Allow / Exclude from blocking !sub.example.com
* Wildcard: matches 0 or more characters *.example.com/*, *shorts*
? Single character: matches exactly 1 character example.com/???/
\? Literal question mark (for query strings) youtube.com/watch\?v=*
/regex/ Regular expression rule /.{3,}\.example\.com/
title:*word* Match against tab / page title title:*Shorts*
Tip: In Approved Sites Only mode, all websites are blocked except rules prefixed with !.
